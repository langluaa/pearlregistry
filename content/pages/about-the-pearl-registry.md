The **Pearl Registry** is an encyclopedia dedicated to [[Tom Pearl]]. It aims to be the single, well-organised, well-sourced reference for his life and work.

## How it works

- **Anyone can read** every page, search the registry and browse categories.
- **Anyone can sign in with GitHub.** Signing in only identifies who you are; it asks for your public profile and nothing else.
- **Only the registry owner can edit.** When the GitHub account that owns the registry's repository signs in, editing unlocks automatically: *Edit*, *Create page* and *Delete* appear.
- **Every edit is a git commit.** Pages are stored as Markdown files in the repository, so the full history of every page is preserved. Old revisions and line-by-line differences can be viewed from any page's *History* tab.
