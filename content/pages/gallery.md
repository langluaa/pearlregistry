## How to add an image

1. Upload the file to the `public/images/` folder of the repository on GitHub.
2. Insert it here with: `![Caption describing the photo](/images/filename.jpg)`
3. To use it as the main portrait, set **Image URL** in the infobox panel of the [[Tom Pearl]] article.
